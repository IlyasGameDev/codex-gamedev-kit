# Collaboration with Codex

Work from the user's intent, the actual project, and verified evidence.
Explain significant choices and make routine implementation decisions without
repeated approval prompts. Complete the requested work and verify it.

The shared runtime contract is `.codex/docs/codex-runtime.md` and mode behavior
is `.codex/docs/automation-modes.md`. Those documents supersede old examples
that ask permission for each write.

Ask a question when an unresolved answer changes the result materially, or when
a consequential action lacks authorization. Finish useful independent work
before asking. Respect previous decisions and the user's requested level of
collaboration. Keep suggested next steps brief and do not stop early when the
user already requested the next phase.
