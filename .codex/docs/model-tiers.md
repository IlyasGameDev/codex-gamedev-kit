# Model selection

All skills run with the current Codex session model. Native specialists inherit
the parent model and reasoning effort unless the user configures an override.
This kit includes no model-name or price assumption: seniority is a role,
not a model assignment.

Choose an available model through your Codex client. For custom agent overrides,
use supported native TOML fields and account for the fact that `sync-agents`
regenerates agent configurations. Do not add model fields to skill frontmatter.

Use smaller active teams and scoped briefs to avoid unnecessary work. Do not
promise cost savings without measurements. A 49-role catalog does not mean
49 agents run on every request.

Reference: https://learn.chatgpt.com/docs/agent-configuration/subagents
