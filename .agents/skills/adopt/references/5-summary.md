# $adopt — Phase 5: Present the Adoption Findings

## Phase 5: Present the Findings

Show the detected engine and project state, the numbers of documents inspected,
and the actual blocking gaps. Distinguish missing artifacts from artifacts that
exist but violate a format the next workflow requires.

Group findings as `BLOCKING`, `HIGH`, `MEDIUM` or `LOW`, with concrete file
references. Explain the specific downstream consequence of each blocking item.
Do not invent a remediation time from a document count.

If an earlier adoption plan exists, say that the new analysis describes current
state. Inspect any same-day output path before deciding whether to update it
or create a distinct report.

When the user requested an adoption plan and ordinary writes are authorized,
continue to Phase 6 and save it. If the request was audit-only, return the
findings without creating a file. If a material write decision remains
unresolved, present the prepared plan and ask one clear question through the
available interaction surface. Never require a particular question tool.
